# 架构与业务规则

## 数据流

企业资料与产品目录 → 单品或组合开发选择 → 客户资料与依据 → 草稿起草与人工审核 → 联系和跟进记录 → 销售阶段与事件统计。

## 主要模块

- `workflow.ts`：客户开发状态、审核门禁和活动事件。
- `product-groups.ts`：产品组合和开发上下文。
- `persistence.ts`：浏览器本地保存及数据版本迁移。
- `discovery.ts`：公开客户候选与官网核对。
- `document-import.ts`、`import-workflow.ts`：资料提取、预览确认与入库。
- `client-ai.ts`、`ai.ts`：模型请求适配、版本保护与结果处理。

评分使用确定性规则；在线模型辅助事实分析和邮件表达。版本令牌保护人工编辑，避免迟到响应覆盖新内容；修改邮件会使先前审核失效。

公开来源客户须经人工确认后加入当前开发选择。统计按已记录事件计算，同一客户可以出现在多个节点，后续阶段不自动推定前置事件。

企业、产品及客户信息更新会影响关联开发选择；各选择的草稿、进展和活动分别保存。

## 运行模式

应用采用 Next.js 服务端和浏览器客户端。默认本地模式使用浏览器存储，无需模型密钥；在线服务通过服务端环境变量配置。完整操作流程见 README。
